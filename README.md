# 🚗 AutoParts – Automotive Services & Spare Parts Landing Page

A modern, responsive, and RTL-optimized landing page designed for auto repair centers, car maintenance workshops, and spare part suppliers. Built with **WordPress**, **Astra Theme**, and **Elementor Page Builder**.

---

## 📸 Key Features
- **Modern & Clean UI/UX:** Styled for automotive services with bold visuals and clean typography.
- **RTL & Persian Localization:** Fully customized Persian layouts and menus.
- **Dedicated Service & Team Sections:** Showcase of car services, testimonials, pricing, and mechanics team.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Forms:** Contact forms and callback request modules for customer conversions.

---

## 🛠 Tech Stack
- **CMS:** WordPress 6.x
- **Theme:** Astra
- **Page Builder:** Elementor
- **Backup & Migration:** All-in-One WP Migration

---

## 📥 How to Run / Import Website

The full site package (database, uploaded media, templates, and plugins) is available under GitHub Releases.

1. **Download Backup:**
   - Go to [Releases](https://github.com/PaRsA9000/-autoparts-landing-wordpress/releases/tag/v1.0.0).
   - Download the `.wpress` file (`localhost-20261020-221431-90ty5fublre6.wpress`).

2. **Restore with WordPress:**
   - Install a clean WordPress instance (e.g., using [Local](https://localwp.com/)).
   - Install and activate the **All-in-One WP Migration** plugin.
   - Navigate to **All-in-One WP Migration > Import > File**.
   - Select the downloaded `.wpress` file and confirm the import process.
